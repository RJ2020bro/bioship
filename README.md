# BioShip

A USABO-scope biology study game set in a 3D ocean world (three.js): sail a continuous voyage through 21 islands in 7 seas, answering questions to defeat each island's monster and open its treasure chest on the beach. Drag to look around; tap the water, ship, monster or island to interact.

- Easy / Medium / Hard difficulty (timer, hull, question level)
- Normal and Hardcore modes, plus a full progress reset
- 213 original questions at USABO/AP Biology level, dealt from per-topic shuffled decks so they don't repeat, with answer lengths balanced so the longest option isn't a giveaway

**Play:** https://rj2020bro.github.io/bioship/

## Layout
- `index.html`: current game (redesign v6, 3D)
- `versions/redesign/`: redesign v1 to v6
- `versions/original/`: original game, bug-fixed and rebalanced copies

Each file is a single self-contained HTML page (three.js r149, MIT, is inlined). Open it in a browser to play.
