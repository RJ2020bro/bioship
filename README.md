# BioShip

A USABO-scope biology study game: sail a continuous voyage through 21 islands in 7 seas, answering questions to defeat each island's monster and claim its treasure. Normal and Hardcore modes, plus a progress reset on the title screen.

**Play:** https://rj2020bro.github.io/bioship/

## Layout
- `index.html`: current game (redesign v5)
- `versions/redesign/`: redesign v1 to v5
- `versions/original/`: original game, bug-fixed and rebalanced copies

Each file is a single self-contained HTML page. Open it in a browser to play.
